# HS للنقل البري 🚕

**نموذج أولي تفاعلي كامل** لتطبيق نقل بري محلي داخل المملكة العربية السعودية (شبيه بأوبر) — مبنى بـ **Flutter** بواجهة عربية **RTL** بالكامل وعملة الريال السعودي (ر.س).

جاهز للمعاينة التفاعلية في المتصفح من بيئات الـ sandbox، وببناء APK عبر GitHub Actions.

</div>

---

| الطبقة | التقنية |
|---|---|
| الإطار | Flutter 3.47 stable · Dart 3.13 |
| الواجهة | Material 3 عربية RTL بخط **Cairo** |
| الخريطة | **flutter_map + OpenStreetMap** — بلا مفاتيح API مدفوعة |
| الحالة | `ChangeNotifier` واحد (`RideStore`) مشترك بين الدورتين — "Mock Service" |
| التنقل | شاشة بداية للتبديل السريع بين وضع الراكب ووضع السائق |
| المنصات | ويب (معاينة sandbox) · أندرويد (APK عبر CI) · iOS |
| الجودة | `flutter analyze` صفر مشاكل + جناح اختبارات (وحدات + ويدجتس) |

## ماذا يعرض النموذج؟

### دورة الراكب (العميل) 🧍
- **خريطة تفاعلية** (OpenStreetMap) لمواقع افتراضية في **الرياض وجدة** (برج المملكة، مطار الملك خالد، الدرعية التاريخية، نافورة الملك فهد…).
- تحديد **نقطة الانطلاق والوجهة** من قائمة مواقع حقيقية الإحداثيات.
- اختيار **فئة المركبة**: اقتصادي / عائلي / VIP مع **تكلفة تقديرية ومسافة ومدة** تُحسب فورياً (haversine + تسعيرة محلية).
- **تأكيد الطلب** ومتابعة حالة الرحلة لحظياً: جاري البحث عن كابتن ← الكابتن في الطريق ← وصل الكابتن ← بدأت الرحلة ← الوصول والتقييم بالنجوم.

### دورة السائق (الكابتن) 🚗
- **تسجيل سائق جديد**: الاسم، رقم الجوال (تحقق 05XXXXXXXX)، نوع المركبة، رقم اللوحة.
- **لوحة تحكم** بزر (متاح / غير متاح) لاستقبال الطلبات.
- **بطاقة طلب واردة تفاعلية**: موقع الراكب + الوجهة + السعر + المسافة، بأزرار **قبول / رفض**.
- **إدارة الرحلة النشطة**: التوجه للعميل ← وصلت ← بدء الرحلة ← إنهاء الرحلة وتحصيل المبلغ.
- **ملخص الأرباح اليومية**: الإجمالي + عدد الرحلات + سجل الرحلات المكتملة.

### الدورتان في تطبيق واحد 🔄
الجوهر المعماري: **متجر حالة واحد مشترك** — إذا طلب الراكب رحلة ثم بدّلت إلى "وضع السائق"، يظهر الطلب فوراً لدى السائق ويمكنه قبوله وإدارة الرحلة، ثم عد للراكب لتجربة التتبع والتقييم. بلا خادم خارجي وبلا اتصال شبكة (عدا بلاطات الخريطة).

## سيناريو التجربة الموصى به (5 دقائق)

1. من شاشة البداية اختر **وضع الراكب**.
2. اختر انطلاقاً (برج المملكة) ووجهة (مطار الملك خالد) — شاهد الأسعار للفئات الثلاث.
3. اختر فئة واضغط **تأكيد الطلب** — ستظهر شاشة "جاري البحث عن كابتن".
4. اضغط **تبديل الوضع** في الأعلى ثم اختر **وضع السائق** — ستلاحظ تنبيهاً بالطلب المعلّق.
5. سجّل سائقاً (اسم/جوال/مركبة/لوحة) ثم فعّل **التوفر لاستقبال الطلبات**.
6. ستظهر **بطاقة الطلب** الذي أنشأته قبل قليل — اضغط **قبول**.
7. أدِر الرحلة: **وصلت إلى العميل** ← **بدء الرحلة** ← **إنهاء الرحلة وتحصيل المبلغ** — وراقب عداد أرباح اليوم.
8. اضغط **تبديل الوضع** وعد للراكب — ستجد شاشة **التقييم بالنجوم** بانتظارك.
